In Meshy or Tripo:
  1. Image to 3D -> Multi-view. Main image = *_01_front, extra views = side + back.
  2. Style: cartoon / stylised.  Keep symmetry on.  Highest quality / "PBR texture" on.
  3. Ask for a T-pose or A-pose if the tool offers a pose option (the website rig expects T-pose).
  4. Export GLB (or FBX) with textures.  Do NOT use the tool's auto-rig; send me the un-rigged
     mesh and I will fit it to the Mixamo skeleton the website already uses.
  5. Repeat for the physio set.
